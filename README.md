# CO₂ Emissions Analysis and Forecasting Using Python

## Project Overview

This repository presents a Python-based data analysis project investigating historical trends, sectoral contributions, and future projections of CO₂ emissions across six countries: China, the United States, Germany, France, Brazil, and Norway.

The project was conducted as part of the Data Analysis coursework in the Master's programme in Sustainable Energy Systems at the University of Applied Sciences Upper Austria.

## Analysis and Methodology

The project includes:

- **Data preprocessing:** Cleaning, handling missing values, duplicate removal, and outlier detection.
- **Exploratory data analysis:** Historical total and per-capita CO₂ emissions.
- **Sectoral analysis:** Comparison of emissions from electricity and heat, transport, industry, and land-use change.
- **Statistical analysis:** Correlation analysis and comparative visualization.
- **Time-series analysis:** Savitzky–Golay smoothing, decomposition, and autocorrelation.
- **Forecasting:** ARIMA-based CO₂ emissions projections and historical backtesting.

## Tools and Libraries

Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Statsmodels, Scikit-learn, and pmdarima.
